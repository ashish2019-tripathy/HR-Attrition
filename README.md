# HR-Attrition

Project Overview-

The HR Employee Attrition Analysis project is an end-to-end data analytics project focused on analyzing employee attrition and identifying the factors that influence employees to leave an organization.
The project uses Python, SQL, and Power BI to clean, process, analyze, and visualize HR data. It helps understand employee turnover patterns, department-wise attrition, workforce demographics, and other HR-related insights.
The main objective is to transform raw HR data into meaningful insights that can help organizations make better data-driven decisions and improve employee retention.

 Project Objectives-

Analyze employee attrition patterns and trends.
Identify factors influencing employee turnover.
Understand department-wise employee attrition.
Analyze employee demographics and job roles.
Perform data cleaning and preprocessing.
Extract meaningful insights using SQL queries.
Build an interactive Power BI dashboard.
Support HR decision-making through data visualization.

Project Workflow-

1. Data Collection
Collected the HR employee dataset in CSV format for analysis.

2. Data Cleaning & Preprocessing (Python)
Loaded the dataset using Pandas.
Checked missing and duplicate values.
Performed data cleaning and preprocessing.
Prepared the dataset for further analysis.

3. Data Analysis (SQL)
Used SQL queries to analyze:
Employee demographics.
Department-wise attrition.
Job role analysis.
Employee workforce trends.
HR-related patterns and metrics.

4. Data Visualization (Power BI)
Developed an interactive HR Analytics Dashboard to present important HR metrics and insights.
Dashboard components include:
Employee attrition rate.
Total employee count.
Department-wise comparisons.
